# Ticket Management System

A full-stack web application for managing bus tickets. Users can add, edit, and delete trips and tickets, search routes, view schedules, and book tickets.

## Features
- Search bus trips by route and date
- View schedule and availability
- Book tickets
- Add new bus trips and ticket information
- Edit or delete existing tickets

## Tech Stack

### Frontend
- React.js, React DOM

### Backend
- Node.js + Express.js, cors, dotenv

### Database
- MySQL (via mysql2)
